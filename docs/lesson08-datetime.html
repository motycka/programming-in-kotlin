Working with date and time

Working with date and time

Using java.time

Kotlin does provide date and time library in the SDK. Instead, you can use Java's java.time package for date and time operations.

There is kotlinx-datetime library, which is a multiplatform library for working with dates and times in Kotlin, but you need to add it as an extra dependency to your project.

For most of the cases, however, java.time should be sufficient.

Java Time

The java.time package contains tools to work with dates, time, intervals and durations.

java.time replaced date and time related tools from java.util, which was not well-designed, was cumbersome to use, did not provide good way fo handling time zones and was not thread safe (!!!).

For these reasons, it was often substituted with 3rd party libraries such as joda.time, which you may come across in older projects.

The current java.time package, however, is generally considered to be good implementation, and you should be using it whenever you are working with Java 8 newer.

Java Time

Here are the tools you will find in java.time.
Clock A clock providing access to the current instant, date and time using a time-zone.
Duration A time-based amount of time, such as '34.5 seconds'.
Instant An instantaneous point on the time-line.
LocalDate A date without a time-zone in the ISO-8601 calendar system, such as 2007-12-03.
LocalDateTime A date-time without a time-zone in the ISO-8601 calendar system, such as 2007-12-03T10:15:30.
LocalTime A time without a time-zone in the ISO-8601 calendar system, such as 10:15:30.
MonthDay A month-day in the ISO-8601 calendar system, such as --12-03.
OffsetDateTime A date-time with an offset from UTC/Greenwich in the ISO-8601 calendar system, such as 2007-12-03T10:15:30+01:00.
OffsetTime A time with an offset from UTC/Greenwich in the ISO-8601 calendar system, such as 10:15:30+01:00.
Period A date-based amount of time in the ISO-8601 calendar system, such as '2 years, 3 months and 4 days'.
Year A year in the ISO-8601 calendar system, such as 2007.
YearMonth A year-month in the ISO-8601 calendar system, such as 2007-12.
ZonedDateTime A date-time with a time-zone in the ISO-8601 calendar system, such as 2007-12-03T10:15:30+01:00 Europe/Paris.
ZoneId A time-zone ID, such as Europe/Paris.
ZoneOffset A time-zone offset from Greenwich/UTC, such as +02:00.
Source: Oracle Java SE 8 documentation

LocalDate

java.time

LocalDate

LocalDate allows us to work with dates without time zone. Here are some examples.

Get today's date

						
							val dateNow = LocalDate.now()

Get a specific date

						
							val date = LocalDate.of(2024, 2, 20)

Parse an ISO-8601 format date

						
							val date = LocalDate.parse("2024-02-20")

Manipulate dates

						
							val tomorrow = LocalDate.now().plusDays(1)

							val nextPeriod = LocalDate.now().plusMonths(3)

							val lastYear = LocalDate.now().minusYears(1)

ZonedDateTime

java.time

ZonedDateTime

ZonedDateTime adds time zones ...
Examples: 
						
							val zonedDateTimeNow = ZonedDateTime.now() // 2024-01-14T09:44:26.147022+01:00[Europe/Prague]

Convert ZonedDateTime to LocalDateTime 

						
							val localDateTimeNow = zonedDateTimeNow.toLocalDateTime()) // 2024-01-14T09:44:26.147022

Convert LocalDateTime to ZonedDateTime 

						
							val zonedDateTime = LocalDateTime.now().atZone(ZoneId.of("Asia/Bangkok")) // 2024-01-14T09:44:26.150263+07:00[Asia/Bangkok]

Convert between zones using Instant

						
							val zonedDateTimeNow = ZonedDateTime.now() // 2024-01-14T09:44:26.147022+01:00[Europe/Prague]

							val zonedDateTime = zonedDateTimeNow.withZoneSameInstant(ZoneId.of("Asia/Bangkok")) // 2024-01-14T15:44:26.147022+07:00[Asia/Bangkok]

Instant

java.time

Instant

To work with zoned date and time correctly, we need to understand the concept of an instant.
  • Instant represents an instantaneous point on the time-line.
  • Instant stores date and time information in UTC (Coordinated Universal Time) format.
  • Instant doesn't contain any information about time zones and doesn't take daylight saving time into account.
  • Instant is useful for applications requiring a high degree of time precision.
  • You can easily convert Instant to DateTime, LocalDateTime, ZonedDate ZonedDateTime, but to convert to Instant, you need to specify time zone. 
						
							val instantNow = Instant.now() // 2024-01-14T09:01:00.878577Z

							val localDateTime = LocalDateTime.now() // 2024-01-14T10:01:00.896618

							val zone = ZoneId.of("Asia/Bangkok")
							val zoneOffset = zone.rules.getOffset(localDateTime)
							val instant = localDateTime.toInstant(zoneOffset) // 2024-01-14T03:01:00.896618Z

Or you can use hard-coded offset, which will however possibly not reflect daylight saving time.

						
							localDateTime.toInstant(ZoneOffset.ofHours(6)) // 2024-01-14T04:01:00.896618Z

Duration

java.time

Duration

Duration helps us measure time amount between instants.
						
							val from = ZonedDateTime.parse("2024-01-14T09:44:26.147022+01:00[Europe/Prague]")
							val to = ZonedDateTime.now()

							val duration = Duration.between(from, to)

							println(duration) // PT21M15.740325S
							println(duration.seconds) //1275
							println(duration.nano) // 740325000

BigDecimal

java.math

BigDecimal

BigDecimal is a Java class which is part of the java.math package and provides arbitrary-precision signed decimal numbers.

So far we used Double and Float to represent floating point numbers, but these types have limitations in terms of precision and rounding errors.

BigDecimal is better choice when we need to represent numbers with high precision, such as when working with very large or very small numbers.

Also, as it stands, you will likely be working with Java libraries which may use BigDecimal.

It's use, however, comes with a cost of performance and memory consumption, so it should be used only when necessary.

It has methods such as add(), subtract(), multiply(), divide(), pow(), sqrt() and cbrt(). 

						
							// parse big decimal from string
							val radius = BigDecimal("987654321.12345678901234567890")

							// get big decimal value from other types
							val two = BigDecimal.valueOf(2)

							// get big decimal representation of pi
							val pi = BigDecimal.valueOf(Math.PI)

							val circleCircumference = two.multiply(pi).multiply(radius)

							println(circleCircumference) // 6205615119.05533231868504652218099103339093540

Java Optional

java.util

Java Optional

Optional is Java container object which may or may not contain a non-null value.

Its purpose is to provide a type-level solution in Java for representing optional values instead of using null.

It forces the user to think about the possibility of a value being absent by requiring the user to explicitly unwrap the value.

This in contrast, null values can be accessed without any checks and therefore can lead to NullPointerException.

It was introduced in Java 8 and resides in java.util package.



Hold on this is a Kotlin class! Why do we need to know?

Because in real world you will be working with Java libraries and frameworks, and you may come across Optional in their APIs.

Java Optional

						
							import java.util.Optional

							fun main() {
								// create an instance of Optional
								val optional: Optional<String> = getRandomValue()

								// check if the value is present
								val isPresent = optional.isPresent
								println("Value is present: $isPresent")

								// you can also use orElse method to provide a default value
								val result = optional.orElse("Optional is cool!")
								println("Value: $result")

								// or in a functional way
								val result2 = optional.orElseGet { "Optional is cool!" }
								println("Value: $result2")

								try {
									// or to throw an exception if the value is not present
									optional.orElseThrow { RuntimeException("Value was not present") }
								} catch (e: RuntimeException) {
									println(e.message)
								}
							}

							private fun getRandomValue(): Optional<String> {
								return Optional.ofNullable(listOf(null, "Java is \"fun\"!").random())
							}
